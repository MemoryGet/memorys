# 本地多知识库检索

本地 PostgreSQL 检索现在支持一次请求选择多个已授权知识库。由于发布投影和 `ConfiguredPlans` 保持“一次调用绑定一个知识库”的完整性边界，`pkg/localruntime` 会先通过当前 Authorizer 解析省略的知识库列表，再对每个知识库执行完整的认证、当前发布、索引和证据校验流程。

所有分片都成功后，运行时才会合并结果。合并仅按候选分数降序排列，并用知识库 ID、块 ID、路由 ID 和检索器 ID 做稳定的并列排序；随后按请求 `limit` 截断并重新编号 `rank`。任何一个分片失败都会拒绝整个请求，避免返回无法说明完整授权范围的部分结果。每个分片的候选仍分别经过 `knowledge.SearchService` 的当前性检查，合并函数不修改正文、引用或代际信息。

当前范围是本地关键词检索。语义/混合路线、跨后端路由和问答生成仍应在各自的统一协调器中复用同样的“按知识库分片、全量成功后合并”规则，而不能直接把多知识库列表传给单知识库发布投影。
