# 验收微任务拆分

当前完整验收由多个长阶段组成，任何一个阶段中断都会让整轮不能完成。后续按下面的微任务推进；每个任务单独结束、单独保存产物，不能把阶段性通过写成最终验收通过。

## 规则

每个微任务必须有固定输入、明确时限、独立输出和一个可判定的结果。长时间任务按“准备、执行、复核、封存”四步拆开；执行中断时只封存该任务的失败或未完成状态，不自动重试，也不把旧数据拼入新轮。
