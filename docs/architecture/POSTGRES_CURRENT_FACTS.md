## 当前事实的来源

同一次只读 Repeatable Read 事务读取每个请求知识库的当前配置绑定、当前审核策略头和空间当前授权策略版本。授权版本必须与刚获得的 AccessScope 一致。找不到绑定、审核规则或授权版本时拒绝，不回退到请求数据。

`query_profile_bindings` 保存空间/知识库内不可变的配置引用版本及摘要；`query_profile_heads` 指向当前引用。引用不能修改、删除；当前指针只能提升版本。回退配置内容需要创建新的引用版本。多个请求知识库必须使用相同的请求流水线摘要，否则拒绝该批次。

事实源返回数据库读到的摘要，不用请求摘要充当当前值。`AuthenticatedControl` 比较数据库结果与请求固定摘要，配置已切换时终止旧请求；随后当前证据检查继续验证知识发布、审核和来源事实。整个过程受请求、授权范围和调用 context 中最早的 deadline 限制。
