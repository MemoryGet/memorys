# 保留策略与回收闸门契约 V1

本规范细化 [数据模型](DATA_MODEL.md)第5节及[一致性协议](CONSISTENCY.md)第4–6节，是D-04的部分机器契约。尚未实现生产回收器、保留锁仓储、迁移导出包或部署归一化。保留期限不是删除许可。

## 1. 版本化策略

[JSON Schema](schemas/retention-policy.v1.schema.json)将所有期限显式定义为正的有符号64位整数秒。`policy_id + policy_version`不可变，必须进入后续部署锁与迁移记录。没有自动默认期限，也不接受0表示无限保留；永久保留通过权威保留锁表达。示例中的数值只是检查边界，不能视为商用或合规推荐。

| 字段 | 语义与起点 |
|---|---|
| rollback_window_seconds | 恢复业务写入后支持回退的最短窗口；记录实际恢复写入时间，而不是开始复制时间 |
| replay_budget_seconds | 预算内完成日志重放与验证的最长时间；超预算保持维护/保留状态，不强行切换或删除 |
| recovery_margin_seconds | 回退和恢复预留的保护时间；不是恢复能力已验证的证明 |
| journal_min_seconds | 每条日志提交后最短保留时间；迁移保留锁可以延长，不能缩短 |
| original_min_seconds | 原件和附件逻辑确认后最短保留时间；实际引用和迁移锁优先 |
| audit_min_seconds | 审计提交后最短保留时间；不与原件或日志期限共用 |
| idempotency_min_seconds | 操作首次接受时即创建幂等记录；终态结果从终态提交起至少保留此时长，非终态不得按此时长清理 |
| retry_window_seconds | 对终态操作承诺返回既有结果的重试窗口，从终态提交开始；窗口后明确返回过期，不能静默再次执行旧命令 |
| max_attempt_seconds | 单次执行尝试的最大运行预算；生产端必须约束续租，不能无限续租绕过期限 |
| cancel_settle_seconds | 取消后等待外部写入停止或隔离确认的预算；预算耗尽仍未知时保持隔离和保留锁 |
| orphan_grace_seconds | 孤立产物从权威登记时间起的最短保护期；任何有效执行、上传或迁移保留锁覆盖此期限 |

离线检查还要求：

```text
journal_min_seconds, original_min_seconds
    >= rollback_window_seconds + replay_budget_seconds + recovery_margin_seconds
idempotency_min_seconds >= retry_window_seconds
orphan_grace_seconds >= max_attempt_seconds + cancel_settle_seconds
```

加法必须检测64位溢出。策略变更不能追溯缩短已承诺的保留截止时间或正在运行的迁移回退窗口；先计算新旧期限的较晚者，只有窗口结束且引用/锁都清除后才可能回收。首次接受后至终态之间始终保留幂等键，服务恢复不能重新接受同一未终结操作。

## 2. 权威保留锁与回收闸门

迁移开始时，在同一权威事务创建保留锁，覆盖旧/新代际、原件、标准内容、日志与墓碑；尚未确定切换/恢复写入时间时锁没有自动到期时间。恢复写入时记录回退截止时间，至少增加重放预算和恢复保护期。进入回退、重放或故障恢复状态时继续持锁，不能因墙钟到期直接释放。

每次物理删除必须读取权威引用和锁：存在有效版本、草稿附件、任务尝试、上传确认、迁移/恢复或人工保留时拒绝。引用计数、缓存、外部索引不存在等不能单独证明可删。授权不够、数据库不可用或状态未知同样拒绝。

检查和标记`purging`必须在事务内通过资源版本CAS线性化；所有创建新引用/锁的路径必须检查该资源状态，禁止引用已标记物理删除的资源。合法复用先取消尚未发出的删除计划，已发出或结果未知时创建新的物理副本与绑定，不能清除墓碑假装删除没有发生。

外部删除使用独立任务和幂等删除标识。超时或返回未知不会将资源标为已删除；保持墓碑、隔离与重试记录，查询路径继续拒绝访问。完成确认仅修改该资源对应状态，不能清掉迁移日志中的撤回/权限墓碑。备份恢复仍按一致性协议补回新水位变更。

## 3. 验证与尚未完成的证据

执行 `python -m unittest discover -s docs/architecture -p test_retention_contract.py`：检查有效边界、回退与重放/恢复关系、幂等期限、取消等待、非法值、精确整数及溢出。检查函数只返回成功或错误，永远不生成删除许可。

这些测试证明策略结构及算术拒绝路径；不证明事务、真实保留锁、并发GC、时间来源或外部删除已实现。生产验收还需注入新引用与删除竞争、迁移超时、无限旧Worker、幂等过期重试、备份恢复和删除未知结果，核对原件/墓碑不会丢失。D-04的BuildLock、ExportManifest、迁移水位机器契约以及正式配置/持久化epoch对照仍待完成。
