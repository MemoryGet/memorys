# 本地解析任务状态

本地上传入口现在为每次解析创建持久化 `parse-tasks.json` 任务记录。请求仍可等待最终结果以保持原有工作台兼容，但任务从 `queued` 进入 `running` 后会保存 attempt、row version、阶段、错误和结果摘要；任务列表、SSE 快照和详情接口可以观察它。

任务输入文件暂存在本地运行目录，完成后删除；失败或取消时保留以支持同一输入重试。取消通过任务上下文中止解析器，重试要求客户端携带当前 row version。进程重启会把遗留 `running` 任务安全标成可重试的 `failed`，不会伪造候选内容或发布结果。

当前解析任务仍由本地工作台宿主执行。生产多进程部署需要把同一状态机迁移到 PostgreSQL/Redis 任务表，并由独立 parser Worker 消费。
